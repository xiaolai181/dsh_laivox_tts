# 小說配音（LaiVox）

在 DeepSeek Harness 裡，把 TXT、EPUB、PDF 小說製作成可收聽的有聲書，也能一鍵把 AI 的回答讀給你聽。預設內建線上語音，無須註冊帳號，安裝後即可使用。

首次開啟會自動在書架放好兩本試聽範例——《社戲 · 月夜行船 · Edge》（單人朗讀）與《綠野仙踪 · 營救鐵皮人 · LaiVox》（多角色配音），點開即可直接試聽效果，不需要時可隨時刪除。

## 核心功能

- **把小說變成有聲書**：匯入 TXT、EPUB 或 PDF，自動辨識章節放進書架；也可以直接新增書籍貼上正文。選好章節後邊生成邊聽，不必等整章完成。
- **單人朗讀，或多角色配音**：單人朗讀開箱即用；切換至「多角色演繹」後，由你設定的 AI 模型分辨說話人與語氣，為每個角色分配獨立音色。
- **一鍵聽 AI 回答，隨手朗讀片段**：點按助手回答旁的「用 Edge 朗讀」，或直接請 AI 讀給你聽；也可以用 `/laivox` 朗讀任意一段文字，產生的片段會收納在「書架 → 對話音訊」中，方便回聽或存進書架。
- **讓 AI 當你的有聲書助手**：在對話裡直接請 AI 查書架、匯入工作目錄中的電子書或規劃整本製作；AI 交付的 TXT、EPUB、PDF 檔案也支援一鍵「匯入到 LaiVox」。所有匯入與呼叫 AI 模型的步驟都會先顯示預覽與預計次數，經你確認後才會開始。
- **專注收聽，也能匯出帶走**：支援倍速播放、睡眠定時、進度續聽、書籤與隨讀高亮；可匯出單章 MP3 / WAV，或將整本書打包匯出為 ZIP。

## 配音引擎選擇

- **微軟 Edge 線上語音（預設）**：開箱即用，無須帳號，適合單人朗讀、多角色基礎分音色與對話訊息朗讀。
- **LaiVox 擬人配音（選用增值）**：在「設定 → 製作與發聲」中切換。支援依每句語氣進行擬人情感演繹，也能在角色選音時使用你在 LaiVox 瀏覽器擴充功能上傳的「我的音色」。使用 LaiVox 會員朗讀額度，或單獨購買朗讀時長包即可啟用。

## 隱私與使用說明

- **介面語言**：跟隨 DSH「設定 → 一般 → 語言」，支援簡體中文、繁體中文與英文。
- **本機保存**：書架、正文、台詞與已產生的音訊皆保存在本機；對話音訊預設在 7 天未聽後自動清理（可在設定中修改或改為永不清理）。
- **線上語音說明**：朗讀或製作時，待合成的文字會傳送至你選擇的線上語音服務（微軟 Edge 或 LaiVox）；單人朗讀不會消耗 DSH 模型額度。
- **PDF 說明**：支援包含可選取文字的 PDF，暫不支援純圖片掃描版。
