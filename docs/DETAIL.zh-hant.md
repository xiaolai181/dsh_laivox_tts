# 小說配音（LaiVox）

在 DeepSeek Harness 裡把 TXT、EPUB 或文字型 PDF 小說製作成可收聽的音訊，也能朗讀對話裡的文字。

## 可以做什麼

- 匯入 TXT、EPUB 或文字型 PDF，分章放進書架。
- 製作單人朗讀或多角色配音。預設使用 Edge 線上語音，無須帳號。LaiVox 付費會員可在「設定 → 製作」切換至 LaiVox 引擎，使用帳號的朗讀額度，並選用在 LaiVox 瀏覽器擴充功能裡上傳的音色。
- 在對話裡使用 `/laivox`，或讓 AI 提出朗讀。若需要 AI 清理正文或編劇，請先在回答下方確認。
- 用助手訊息旁的「用 Edge 朗讀」讀出回答，也可以請助手直接朗讀。
- 請 AI 搜尋書架、新增書籍或章節、預覽工作區裡的 TXT、EPUB 或文字型 PDF，或建立製作單。匯入與製作會先請你確認。也可以用對話檔案旁的按鈕匯入 AI 交付的文件。
- 播放、調整速度、設定睡眠定時、跳到指定段落，以及匯出 MP3 或 WAV。

## 對話與播放

- 待確認的朗讀提案、製作單和匯入預覽會顯示在最新一則回答下方，也可以在工具卡片上確認。
- 輸入欄上方的 LaiVox 列會顯示待確認項目、製作進度及「繼續聽」。可以按 × 隱藏，也可以在設定中調整何時顯示。
- 最近的結果會顯示在最新一輪對話末尾，可以在對話內試聽或到工作台開啟章節。
- 朗讀回答時會暫停小說，朗讀完成後可從迷你播放器選擇「繼續聽」。
- 對話音訊會依對話分組，放在「書架 → 對話音訊」。超過保留期限未收聽的項目會自動刪除，預設為 7 天，可在設定中變更。

## 語言與資料

- 在 DSH「設定 → 一般 → 語言」選擇簡體中文、繁體中文或英文，工作台會跟隨切換。
- 書籍資料保存在 Profile 的 `dsh-laivox-tts` 資料夾。舊版 `laivox-novel-audio` 資料夾不會自動移轉。舊版外掛無法開啟目前的 v12 資料庫，升級前請先備份。
- 空白 Profile 首次啟動會在書架寫入兩本免 Key 試聽範例（《社戲 · 月夜行船 · Edge》範例音訊由微軟 Edge 線上語音生成，《綠野仙踪 · 營救鐵皮人 · LaiVox》由 LaiVox 預設音色生成），可隨時刪除且刪除後不會重現。
- 朗讀時會把文字送到 Microsoft Edge 線上語音服務。
