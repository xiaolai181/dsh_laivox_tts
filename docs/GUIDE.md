# 小说配音（LaiVox） · 使用指南

LaiVox 是 DeepSeek Harness（DSH）里的有声书插件：把 TXT / EPUB / PDF 小说做成单人朗读或多角色配音的音频，也能把 AI 的回答直接读给你听。默认使用 Edge 在线语音，不需要注册账号。

从侧栏的「小说配音（LaiVox）」进入工作台。顶部三个页签：**收听**、**制作**、**书架**；右上角是任务和设置。首次打开（或上次收听的章节已被删除）会进入书架；之后再打开会回到上次收听的章节。

> 从旧版升级：第一次打开新版前，先完全退出 DSH，备份 Profile 下的 `dsh-laivox-tts` 目录。新版会升级书架数据库，旧版之后打不开它。

---

## 场景一：手里有一本小说，想听

1. **书架 →「导入 TXT / EPUB / PDF」**，选择文件。预览里能看到分章结果和正文样例；分章不对可以点章节标题调整，或用「AI 辅助分章」。确认后点「导入 N 章」。
2. 打开一章，在制作条选择：
   - **单人朗读**：直接合成，不用 AI。
   - **多角色演绎**：AI 先标注谁在说话、什么语气，再按角色配音。开始前会列出预计请求数和额度提示，确认后才调用 AI。
3. 点「开始制作」。前两段合成好就可以播放，不用等整章。
4. 要一次做很多章：书架里点「批量选择」，选好后「批量生成」。

**听**：点播放，支持倍速、定时关闭、书签，正文跟着高亮。一章播完会自动续播下一章（可在设置里关闭）。

**导出**：单章在播放器的「更多」（⋯）里下载 MP3 / WAV。整章文件需要先在本机准备好，播放条下方会显示「正在准备 MP3 · 已完成段数 / 总段数」，可以随时点「取消」；准备好后自动开始下载。整本在书架目录标题旁的「书籍操作」里导出为 ZIP，重命名、清理书中音频、删除本书也在这个菜单里。

**角色与音色**：制作页的「角色」里，每个角色都显示它实际会用的音色；自动分配的写成「自动 · 音色名」。点音色按钮打开选择面板，选好后点底部的「使用此音色」立即保存，下次合成生效。新书的自动分配按性别和年龄挑选（AI 编剧会给新角色标年龄段，也可以在「编辑」里修改）；之前建的书保持原来的分配，角色页顶部会提示，可点「按新规则重新分配」，确认前会列出哪些角色会换音色。改了角色的性别或年龄、导致其他角色的自动音色跟着变化时，保存前会提示。两个角色用了同一个音色、而还有别的音色可选时，角色卡上会提醒。

**重新合成一段**：用 LaiVox 时，台词页里已合成的段落旁有「重新合成」。听着不满意可以再做一次，每次的演绎会不同（计入 LaiVox 用量），新音频做好后才替换原来的。本章还有制作任务时要等它结束。

**保存时提示「先停止相关任务」**：修改正文、台词或音色时，如果相关的制作任务还没结束（包括暂停的），保存前需要先停止它们。可以直接选「停止任务并保存」；修改台词时还可以选「停止任务，保存并继续制作」。已经合成好的音频会保留，重新制作时直接复用。

**手动粘贴正文**：在书架顶部点「新建书籍」，填写书名和首章正文。章节标题可选，留空时会用正文首行。给已有书籍添加内容时，先在书架点击该书，再点章节目录旁的「添加章节」。点击书卡只会显示目录，点击具体章节才会进入收听。

## 场景二：让 AI 帮你把网上的小说做成有声书

在对话里直接说就行，例如：

> 把工作目录里的 `book.txt` 做成有声书。

AI 会先生成**导入预览**，在它回答的正下方显示：

`《书名》· 导入预览 · 32 章　[导入] [在工作台预览]`

点「导入」入架；想先检查分章就点「在工作台预览」。随后 AI 会给出**制作单**：

`《书名》· 制作 32 章 · 单人朗读　[确认制作] [忽略] [章节]`

点「确认制作」后开始排队合成。AI 发起的任务排在你已有的任务后面，**不会打断你正在做的书**。

其他可以交给 AI 的事：

- **问书架**："我的书架上有哪些书？哪些章还没做音频？"
- **追加章节**："把这两章加到《某某》后面。"同名且正文相同的章节会自动跳过。
- **交付文件**：AI 生成的 `.txt` / `.epub` / `.pdf` 文件卡片上有「导入到 LaiVox」，一键打开导入预览。

AI 只能读当前对话工作目录里的文件，不能删除你的书。需要导入或花模型额度的步骤，都要你点确认。

## 场景三：把 AI 的回答读给我听

- **点按钮**：每条回答下方（复制、点赞旁边）的喇叭「用 Edge 朗读」。正在读时变成停止键；右下角的迷你播放器显示进度，也可以从那里停止。
- **直接说**："读给我听：……"或"用语音回答我"。AI 会直接开始朗读，只用一句话回复你。

朗读会跳过已闭合的代码块和链接地址，表格会读出单元格里的文字。如果你正在听小说，开始朗读时小说会暂停；读完后迷你播放器提示「继续听」，点一下从原来的位置接着听。按下小说的播放键，朗读会停止。

音色按文字的语言自动选择，可在 **设置 → 对话消息朗读（Edge）** 为简体、繁体、英文各选一个并试听。朗读的文字会发送到微软 Edge 在线语音服务。

## 场景四：在对话里快速听一段文字

在输入框输入：

```
/laivox 要朗读的一段文字
```

| 写法 | 效果 |
|---|---|
| `/laivox 正文` | 按默认设置制作 |
| `/laivox --reading 正文` | 单人朗读，不用 AI，直接开始 |
| `/laivox --clean 正文` | 先用 AI 清洗正文 |
| `/laivox --cast 正文` | 多角色配音 |
| `/laivox status` | 查看本对话最近的任务 |
| 只发 `/laivox` 并附上 TXT/EPUB/PDF | 生成导入预览 |

需要 AI 处理时，回答下方会出现确认行（字数、是否用模型额度），点「确认生成」才开始；「调整」可以修改正文和选项。完成后回答下方会出现结果，点「试听」直接在对话里播放。

输入框上方的 LaiVox 栏用一行显示待确认数、制作进度和「继续听」。右侧的 × 可以隐藏当前内容；**设置 → 对话工作条** 可以改成只在有待确认或制作中时显示，或者完全不显示。

## 场景五：管理对话里产生的音频

对话里做出来的朗读不会挤进书架，而是收在 **书架 →「对话音频」**，按会话分组：

- **播放 / 导出**：直接听，或下载 WAV、MP3。
- **⋯ 菜单**：重命名、保存到书架（变成正式的书，以后不会被自动删除）、删除。
- **全部删除**：一次清空；正在制作的会保留。

对话音频超过保留期没听就会自动删除，默认 7 天，从最后一次收听算起。可在 **设置 → 存储** 改为 1 天、30 天或永不；改短时会先告诉你要删掉几条。

---

## 空间不够了

**设置 → 存储** 里可以：

- 调整音频上限（0.5～20 GiB）；
- 清理**旧版音频**（改过正文、换过音色或模式之前生成的音频，当前版本不受影响）；
- 回收数据库空间。

也可以在书架上按章或按书清理音频，正文和台词会保留。

## 常见问题

**点了没反应 / 一直在准备？** 朗读第一句通常要 1～2 秒，之后会更快。网络断开时按钮旁会显示错误和「重试」。

**确认按钮找不到？** 确认按钮都在最后一轮回答的正下方，输入框上方的 LaiVox 栏展开后也能确认。

**AI 制作会花钱吗？** 单人朗读不用 DSH 模型。AI 清洗和多角色编剧会消耗你在 DSH 里配置的模型额度，开始前都会显示预计请求数，由你确认。

**想用 LaiVox 的音色？** 在 **设置 → 制作与发声** 把引擎切换为 LaiVox，并保存官网的 API Key。Key 有两种：LaiVox 会员签发的 Key 使用会员的朗读额度（与 LaiVox 浏览器扩展共用，不占 AI 整理额度）；也可以在设置页点「购买朗读时长包」单独购买，时长包 Key 只扣时长包额度。在 LaiVox 浏览器扩展里上传的音色，会出现在角色音色选择的「我的音色」里；上传和修改仍在扩展里进行。

**LaiVox 额度用完了怎么办？** 制作条会停下并说明原因。还能开启下一个使用日时，点「开启下一个使用日」，确认后点「继续制作」；也可以点「用 Edge 补完剩余段」，剩下的段落改用 Edge 音色，以后额度恢复了再用 LaiVox 重新生成这一章（已经是 LaiVox 的段落会直接复用）。

**付费音频存不进去？** 单章超过音频空间上限时，已经向 LaiVox 提交、但还没写入本地的段落不会继续下载。额度已经扣过的音频如果在网关侧过期，需要重新制作这一章。

### 三个入口，同一套停用规则

| 入口 | 能做的事 | 什么时候不能用 |
| --- | --- | --- |
| 工作台「开始制作」 | 清洗、编剧、合成当前章或选中的章 | 本章已有制作任务 |
| 对话里的制作单 | 确认后排进队列 | 本章已有制作任务 |
| `/laivox` | 从正文生成待确认朗读 | 本章已有制作任务 |

三个入口都不删除。停用条件相同：这一章的制作还在进行。
