# 小说配音（LaiVox）

在 DeepSeek Harness 里把 TXT / EPUB / 文字型 PDF 小说做成可听的音频，也能把对话里的文字读出来。

## 能做什么

- 导入 TXT、EPUB 或文字型 PDF，按章放进书架。
- 单人朗读，或多角色配音。默认用 Edge 在线语音，不需要账号；也可以在「设置 → 制作」改用 LaiVox 引擎：用 LaiVox 会员的 API Key（扣会员的朗读额度），或单独购买朗读时长包（30 小时，60 天内有效）；可用在 LaiVox 浏览器扩展里上传的音色。
- 在对话里用 `/laivox` 或让 AI 提出朗读。需要 AI 清洗或编剧时，先在回答下方确认。
- 助手消息旁的「用 Edge 朗读」把回答读出来；请 AI "读给我听"也会直接朗读。
- AI 可以查书架、建书或追加章节、把工作目录里的 TXT/EPUB/PDF 生成导入预览、为一本书生成制作单；导入和制作由你确认。AI 交付的 TXT/EPUB/PDF 文件旁可一键「导入到 LaiVox」。
- 播放、倍速、定时关闭、从某一段接着听，以及导出 MP3 / WAV。

## 对话里能看到什么

- 待确认的朗读提案、制作单和导入预览显示在最后一轮回答的正下方：摘要、是否使用 DSH 模型额度，以及确认按钮。工具卡上也能确认。
- 输入框上方的 LaiVox 栏收成一行：待确认数、制作进度、继续听；可以用 × 隐藏，也可在设置里改为只在待确认或制作中显示，或不显示。
- 最近一次完成或取消的结果出现在最后一轮末尾。「试听」直接在对话中播放；「打开章节」进入工作台。
- 朗读时迷你播放器显示进度和停止键；朗读会暂停正在听的小说，读完提示「继续听」，不会自动恢复。
- 对话里朗读的结果收在书架的「对话音频」页签，按会话分组，超过保留期未听自动删除（默认 7 天，可改）。

## 限制

- 界面语言跟随 DSH「设置 → 通用设置 → 语言」，支持简体中文、繁体中文和英文。
- 数据目录是 Profile 里的 `dsh-laivox-tts`。旧目录 `laivox-novel-audio` 不会自动迁移。数据库为 v12，旧版插件打不开，升级前请备份。
- 空白 Profile 首次启动会在书架写入两本免 Key 试听示例（《社戏 · 月夜行船 · Edge》示例音频由微软 Edge 在线语音生成，《绿野仙踪 · 营救铁皮人 · LaiVox》由 LaiVox 预置音色生成），可随时删除且删除后不再重现。
- 结果、提案和导入预览只挂在最后一轮，更早的回合不重复。
- 继续听显示段序号和该段内的时间。
- 朗读的文字会发送到微软 Edge 在线语音服务。
